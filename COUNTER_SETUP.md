# Счётчик посетителей «Север»

Счётчик использует отдельный Cloudflare Worker и базу D1. Tuqo остаётся статическим хостингом сайта; на Tuqo серверный код не запускается.

## Что считает

- Приблизительное число уникальных посетителей, активных за скользящие последние 24 часа.
- Повторные обращения с того же IP и User-Agent обновляют время последнего посещения, а не создают новую запись.
- Роботы с типичными бот-маркерами в User-Agent не учитываются.
- Сырые IP-адреса не сохраняются: Worker использует их только для создания SHA-256 отпечатка с секретной солью.
- Записи старше 7 дней удаляются ежедневным расписанием.

Это приблизительный счётчик: смена IP/браузера может посчитать одного человека повторно, а несколько людей за одним IP и одинаковым User-Agent могут объединиться. Не использовать для критичной аналитики или учёта оплат.

## Подготовка Cloudflare

1. Создать аккаунт Cloudflare и открыть раздел Workers & Pages.
2. Создать D1 database с именем `sever-visitor-counter`.
3. В D1 Console выполнить SQL из `counter-worker/schema.sql`.
4. Создать Worker с именем `sever-visitor-counter` и вставить код из `counter-worker/src/index.js`.
5. В настройках Worker добавить D1 binding:
   - Variable name: `DB`
   - Database: `sever-visitor-counter`
6. Добавить секрет Worker `COUNTER_SALT` со случайным длинным значением. Секрет не публиковать в GitHub и не вставлять в код.
7. Добавить Cron Trigger: `17 3 * * *` (ежедневно, UTC).
8. Развернуть Worker и проверить адреса `/count` и `/visit`. До настройки фронтенда они должны возвращать JSON с числом посетителей.
9. Записать публичный URL Worker, например `https://sever-visitor-counter.<account-subdomain>.workers.dev`. Это не секрет.

## После публикации Worker

В `app.js` нужно добавить URL Worker и аккуратный элемент счётчика в футер `index.html`. Фронтенд будет вызывать `/visit` один раз при загрузке страницы, а API вернёт число уникальных посетителей за последние 24 часа. На странице будет показано только число, без подписи о временном интервале.

Не включать счётчик в сайт, пока Worker, D1 binding, секрет и публичный URL не настроены и не проверены. Ошибка счётчика не должна мешать загрузке прогноза погоды.

## Ограничения

- Статистический endpoint публичный; CORS разрешает сайт `https://pogodansk.tuqo.ru`. CORS не является защитой от прямых автоматических запросов, поэтому это лёгкий счётчик, а не антифрод-система.
- Использование IP и User-Agent для создания хешированного идентификатора всё равно является обработкой технических данных. При необходимости добавить короткое уведомление о статистике и политику конфиденциальности.
- Лимиты бесплатного тарифа Cloudflare могут меняться; перед запуском проверить текущие лимиты Worker и D1.
